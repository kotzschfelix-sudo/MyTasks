# MyTasks

MyTasks ist die Aufgabenverwaltung innerhalb von MyDigital.

## Aktueller Stand
- Dunkles, responsives Grundlayout
- Aufgaben lokal erstellen und als erledigt markieren
- Beschreibung, Fälligkeitsdatum und Priorität
- Suche und Filter
- Akzentfarbe auswählen
- Erste PWA-Dateien (Manifest und Service Worker)

## Noch nicht enthalten
- MyDigital-/Supabase-Anmeldung
- Synchronisierung zwischen Geräten
- dauerhaft gespeicherte Projekte und Listen
- Push-Benachrichtigungen und Erinnerungen

**Wichtig:** Die aktuelle Version speichert Aufgaben nur im lokalen Browser (localStorage). Für echte Konten und geräteübergreifende Synchronisierung wird im nächsten Schritt Supabase integriert.
